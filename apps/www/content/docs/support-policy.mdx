ArkEnv follows [semantic versioning](https://semver.org/) (semver). This
page covers runtimes, release types, and what to expect from a version
bump.

v1 is currently published as `1.0.0-alpha.x` under the `alpha` npm tag.
**APIs can still change before 1.0.0.**

## Runtimes

`@arkenv/core` and `@arkenv/standard` run anywhere you can run modern
JavaScript. Framework plugins target a specific host.

| Runtime | Support |
| ------- | ------- |
| Node.js | [Active and Maintenance LTS](https://nodejs.org/en/about/previous-releases) (Node 20, Node 22, Node 24) |
| Bun | 1.0+, including bundler apps via [`@arkenv/bun-plugin`](/docs/reference/bun-plugin) |
| Deno | Runtime validation with `@arkenv/core` or `@arkenv/standard` |

[Examples](/docs/getting-started/examples) are expected to work with
these Node.js versions. CI runs on `lts/*` and `latest`.

## Release types

Stable-style semver still applies on the alpha line: the number tells you
how a change lands, even while the `alpha` tag marks the release as
pre-1.0.

| Type | What it includes |
| ---- | ---------------- |
| **Major** | Breaking API changes or a new minimum Node.js version |
| **Minor** | New features, schema helpers, or framework support without breaking existing behavior |
| **Patch** | Bug fixes, performance work, and documentation |

Use the latest version whenever you can. The
[changelog](https://github.com/yamcodes/arkenv/releases) lists what
changed in each release.
