ArkEnv follows standard Semantic Versioning (SemVer) and Node.js release cycles.

## Node.js & Runtime Support

- **Node.js**: Active LTS versions (Node 20, Node 22, Node 24).
- **Bun**: Bun 1.0+ (supported natively via `@arkenv/bun-plugin`).
- **Deno**: Fully supported for standard schema validation.

## Release Types

- **Major Releases**: May include breaking API changes or minimum Node.js version bumps.
- **Minor Releases**: Add new feature integrations, schema helper functions, or framework support without breaking existing behavior.
- **Patch Releases**: Bug fixes, performance optimizations, and documentation updates.
