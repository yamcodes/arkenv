API reference for `@arkenv/rsbuild-plugin`. Setup recipes:
[TanStack Start guide](/docs/frameworks/tanstack-start#rsbuild).

## Installation

```package-install
npm install -D @arkenv/rsbuild-plugin
npm install @arkenv/core arktype
```

Or if you use Zod, Valibot, or another Standard Schema validator:

```package-install
npm install -D @arkenv/rsbuild-plugin
npm install @arkenv/standard
```

## Exports

| Export                      | Role                          |
| --------------------------- | ----------------------------- |
| default                     | `arkenvPlugin` plugin factory |
| named `arkenvPlugin`        | Plugin factory                |
| named `arkenvRsbuildPlugin` | Host-explicit named alias     |
| `./standard`                | Standard Schema plugin entry  |

## Transform options

Pass transform options only. A schema argument is rejected.

| Option                | Default         | Meaning                                                                                      |
| --------------------- | --------------- | -------------------------------------------------------------------------------------------- |
| `schemaPath`          | auto (`env.ts`) | Schema module to transform                                                                   |
| `clientPrefix`        | `PUBLIC_`       | Keys exposed to the client                                                                   |
| `env`                 | (none)          | Build-time override merged over the loaded environment before the schema module is evaluated |
| `logger` / `logLevel` | (none)          | Logging                                                                                      |

`env` on the plugin is a build-time override for this compile. It is not
the runtime parse source. `env` on [`arkenv()`](/docs/reference/options)
in `env.ts` still selects which record that call validates.

<Callout type="info" title="Runtime options stay on arkenv()">
  Set `coerce`, `onUndeclaredKey`, `arrayFormat`, `emptyAsUndefined`,
  `debugSecrets`, and `toJsonSchema` on `arkenv()` in `env.ts`. The plugin
  rejects them. See [Options](/docs/reference/options).
</Callout>

Call `arkenvPlugin()` (or `arkenvRsbuildPlugin()`) with no args, or an options
object that includes transform fields (`schemaPath`, `clientPrefix`, `env`,
logging). Do not pass a schema map or compiled `type()` to the plugin.
