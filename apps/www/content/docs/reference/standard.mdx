title: "@arkenv/standard"
description: ArkType-free environment validation via Standard Schema.
---

`@arkenv/standard` validates environment variables with any [Standard Schema](https://standardschema.dev/) validator (Zod, Valibot, and others). No runtime dependencies or peers. Install your validator yourself.

Choose `@arkenv/core` when you want ArkType. Choose `@arkenv/standard` when you migrate from Zod/Valibot or keep the tree ArkType-free.

## Install

```package-install
pnpm add @arkenv/standard zod
```

Swap `zod` for your validator of choice.

## Quick start

```ts title="./env.ts" twoslash
import arkenv from "@arkenv/standard";
import { z } from "zod";

export const env = arkenv({
  PORT: z.coerce.number().int().min(0).max(65535).default(3000),
  DATABASE_URL: z.string().url(),
  NODE_ENV: z.enum(["development", "production", "test"]).default("development"),
});
```

## Compared to `@arkenv/core`

|                                    | `@arkenv/core`              | `@arkenv/standard`                                                                              |
| ---------------------------------- | --------------------------- | ----------------------------------------------------------------------------------------------- |
| Validator                          | ArkType DSL + `type()`      | Standard Schema map only                                                                        |
| Peer `arktype`                     | Required                    | None                                                                                            |
| [Options](/docs/reference/options) | Same                        | Same                                                                                            |
| Coercion                           | Built-in for ArkType shapes | Needs JSON Schema introspection (Zod 4.2+, Valibot with `@valibot/to-json-schema`, and similar) |

## Exports

| Export               | Kind                       | Role                                                           |
| -------------------- | -------------------------- | -------------------------------------------------------------- |
| `arkenv`             | function (default + named) | Validate a Standard Schema field map                           |
| `ArkEnvValidationError`        | class                      | Thrown on validation failure                                   |
| `formatIssues`       | function                   | Format issues                                                  |
| `getSchemaKeys`      | function                   | List schema keys                                               |
| Config / issue types | types                      | Same shapes as core (`StandardEnvConfig` aliases core options) |
