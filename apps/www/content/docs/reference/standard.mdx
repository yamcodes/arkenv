title: "@arkenv/standard"
description: ArkType-free environment validation via Standard Schema.
---

`@arkenv/standard` is the ArkType-free validation engine. First-class support
is Zod and Valibot. It consumes
[Standard Schema](https://standardschema.dev/) validators; libraries that only
implement the validate hook may still need a `toJsonSchema` helper or a
dedicated subpath (for example `@arkenv/standard/valibot`). The root import has
no runtime dependencies or peers.

- **If you use ArkType**, use [`@arkenv/core`](/docs/reference/core). **You do not need `@arkenv/standard`**.
- **If you use Zod or Valibot**, use `@arkenv/standard`. This keeps `arktype` out of the tree. **You do not need `@arkenv/core`**.

TypeScript must use `moduleResolution: "bundler" | "node16" | "nodenext"`.

## Installation

```package-install
npm install @arkenv/standard
```

## Usage

<Tabs items={["Zod", "Valibot"]}>
  <Tab value="Zod">
    ```ts title="./env.ts" twoslash
    import arkenv from "@arkenv/standard";
    import * as z from "zod";

    export const env = arkenv({
    	PORT: z.int().min(0).max(65535).default(3000),
    	DATABASE_URL: z.url(),
    	NODE_ENV: z
    		.enum(["development", "production", "test"])
    		.default("development"),
    });
    ```
  </Tab>

  <Tab value="Valibot">
    ```ts title="./env.ts" twoslash
    import { arkenv } from "@arkenv/standard/valibot";
    import * as v from "valibot";

    export const env = arkenv({
    	PORT: v.optional(
    		v.pipe(v.number(), v.integer(), v.minValue(0), v.maxValue(65535)),
    		3000,
    	),
    	DATABASE_URL: v.pipe(v.string(), v.url()),
    	NODE_ENV: v.optional(
    		v.picklist(["development", "production", "test"]),
    		"development",
    	),
    });
    ```
  </Tab>
</Tabs>

## Compared to `@arkenv/core`

Both engines share `arkenv()` options, errors, and framework plugins.
They differ in schema style and peers.

|                                         | `@arkenv/core`              | `@arkenv/standard`                                                                                                                                               |
| --------------------------------------- | --------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Validator                               | ArkType DSL + `type()`      | Standard Schema map only                                                                                                                                         |
| Keywords (`string.host`, `number.port`) | Yes                         | No                                                                                                                                                               |
| Peer `arktype`                          | Required                    | None                                                                                                                                                             |
| [Options](/docs/reference/options)      | `ArkEnvConfig`              | `StandardEnvConfig` (`ArkEnvConfig` plus `toJsonSchema`)                                                                                                         |
| Coercion                                | Built-in for ArkType shapes | Standard JSON Schema on the value, or `@arkenv/standard/valibot` / `/zod-mini` / [`toJsonSchema`](/docs/core-concepts/coercion-and-parsing#valibot-tojsonschema) |

## Exports

These are the public names from `@arkenv/standard`.

| Export               | Kind                       | Role                                                         |
| -------------------- | -------------------------- | ------------------------------------------------------------ |
| `arkenv`             | function (default + named) | Validate a Standard Schema field map                         |
| `ArkEnvError`        | class                      | Thrown on validation failure                                 |
| `formatIssues`       | function                   | Format issues                                                |
| `getSchemaKeys`      | function                   | List schema keys                                             |
| Config / issue types | types                      | `StandardEnvConfig` extends core options with `toJsonSchema` |

### Subpaths

| Import                      | Role                                                                                           |
| --------------------------- | ---------------------------------------------------------------------------------------------- |
| `@arkenv/standard`          | Root engine (throw path). Dependency-free. Zod works zero-config.                              |
| `@arkenv/standard/safe`     | `arkenv` — result object instead of a throw (default + named export)                           |
| `@arkenv/standard/valibot`  | Same `arkenv`, pre-configured for Valibot. `valibot` + `@valibot/to-json-schema` are required. |
| `@arkenv/standard/zod-mini` | Same `arkenv`, pre-configured for Zod Mini. `zod` is required.                                 |

```ts title="./env.ts" twoslash
import arkenv from "@arkenv/standard/safe";
import * as z from "zod";

const result = arkenv(
  { PORT: z.coerce.number() },
  { env: { PORT: "invalid" } },
);

if (!result.success) {
  console.error(result.issues);
}
```

```ts title="./env.ts" twoslash
import { arkenv } from "@arkenv/standard/valibot";
import * as v from "valibot";

export const env = arkenv({
  PORT: v.optional(v.number(), 3000),
});
```
