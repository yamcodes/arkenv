---
title: env
description: The validated env object returned by arkenv().
---

`arkenv()` returns a typed object of validated (and coerced) values. Import that object as `env` and read properties instead of touching `process.env` in application code.

```ts title="./env.ts" twoslash
import arkenv from "@arkenv/core";

export const env = arkenv({
	DATABASE_URL: "string",
	PORT: "number.port = 3000",
});

env.DATABASE_URL; // string
env.PORT; // number
```

## Default source

Without a config object, ArkEnv reads `process.env`. Override with [`options.env`](/docs/reference/options#env) when the host injects variables another way.

ArkEnv does not load `.env` files. Your framework, `dotenv`, or process manager must populate the source before `arkenv()` runs.

## Return shape

| Mode                    | Return type                                               |
| ----------------------- | --------------------------------------------------------- |
| Default (`safe: false`) | Validated object; throws `ArkEnvError` on failure         |
| `safe: true`            | `{ success: true, data }` or `{ success: false, issues }` |

Core and `@arkenv/standard` return a plain object (no Proxy).

## Framework Proxies

Next.js and Nuxt wrap the validated object in a Proxy that:

- Throws if client code reads a server-only key
- Throws if code reads a key that is not in the schema

Vite and Bun plugins rewrite the client graph so only public keys are inlined. The app still imports `env` from your schema module.

See [Client vs. server](/docs/validating-environment-variables/client-vs-server) and [Error reporting](/docs/validating-environment-variables/error-reporting).

## Typing helpers

```ts title="./env.ts" twoslash
import arkenv, { type Infer } from "@arkenv/core";

const schema = { API_URL: "string" } as const;
export const env = arkenv(schema);
export type Env = Infer<typeof schema>;
```

Framework plugins may also augment `ImportMetaEnv` (Vite) or `NodeJS.ProcessEnv` (Bun). Prefer the exported `env` object as the canonical surface.
