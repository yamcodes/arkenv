API reference for `@arkenv/nuxt`. Setup recipes:
[Nuxt guide](/docs/guides/frameworks/nuxt).

## Installation

```package-install
npm install @arkenv/core @arkenv/nuxt arktype
```

Or if you use Zod, Valibot, or another Standard Schema validator:

```package-install
npm install @arkenv/standard @arkenv/nuxt
```

## Subpaths

| Subpath                         | Role                                                     |
| ------------------------------- | -------------------------------------------------------- |
| `.`                             | Runtime `arkenv` for flat layouts                        |
| `./server`                      | Server-only entry                                        |
| `./client`                      | Client entry                                             |
| `./module`                      | Nuxt module (`modules: ["@arkenv/nuxt/module"]`)         |
| `./config`                      | `setupArkEnv` and config types                           |
| `./standard` and `./standard/*` | Standard Schema variants (including `./standard/module`) |

## Module options

These options live under `arkenv` in `nuxt.config`.

| Option                | Default | Meaning                                      |
| --------------------- | ------- | -------------------------------------------- |
| `validate`            | `true`  | Validate during Nuxt build/dev               |
| `layout`              | auto    | `"flat"` or `"strict"` (detected from files) |
| `schemaPath`          | auto    | Schema entry path                            |
| `logger` / `logLevel` | (none)  | Logging controls                             |
