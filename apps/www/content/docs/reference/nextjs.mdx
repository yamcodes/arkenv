`@arkenv/nextjs` adds Next.js-aware `arkenv()` entries, build-time validation, and `env.gen.ts` codegen.

## Install

```package-install
pnpm add @arkenv/core @arkenv/nextjs arktype
```

Or with Standard Schema:

```package-install
pnpm add @arkenv/standard @arkenv/nextjs zod
```

Peers: `next`, `react`. `@arkenv/core` / `@arkenv/standard` / `arktype` are optional depending on dialect.

## Subpaths

| Subpath | Role |
| --- | --- |
| `.` | Unified `arkenv` (`react-server` condition for RSC, default for client/SSR) |
| `./server` | Server-only `arkenv` (`server-only`) |
| `./client` | Client `arkenv` |
| `./config` | `withArkEnv`, `runCodegen`, config types |
| `./standard` | Standard Schema unified entry |
| `./standard/server`, `./standard/client`, `./standard/shared` | Split Standard entries |
| `./standard/config` | Standard `withArkEnv` (forces Standard codegen) |

## Config plugin

```ts title="./next.config.ts"
import type { NextConfig } from "next";
import { withArkEnv } from "@arkenv/nextjs/config";

const nextConfig: NextConfig = {};

export default withArkEnv(nextConfig);
```

By default this writes `generated/env.gen.ts` and validates the schema during config/build. Your app schema imports the generated factory:

```ts title="./env.ts"
import arkenv from "@/generated/env.gen";

export const env = arkenv({
	DATABASE_URL: "string",
	NEXT_PUBLIC_API_URL: "string = 'https://api.example.com'",
	NODE_ENV: "'development' | 'production' | 'test' = 'development'",
});
```

### `withArkEnv` options

| Option | Default | Meaning |
| --- | --- | --- |
| `codegen` | `true` | Write `env.gen.ts` |
| `validate` | `true` | Validate during config/build |
| `layout` | `"flat"` | `"flat"` or `"strict"` |
| `schemaPath` | auto | Schema entry path |
| `outputPath` | auto | Generated file path |
| `standard` | `false` | Standard Schema codegen |

Skip generation during CLI scaffolds with `arkenv init --no-codegen`.

### Programmatic codegen

```ts
import { runCodegen } from "@arkenv/nextjs/config";

await runCodegen(schemaPath, outputPath);
```

Call `runCodegen` from custom tooling. Apps wire generation through `withArkEnv`.

### Standard Schema codegen

```ts title="./next.config.ts"
import { withArkEnv } from "@arkenv/nextjs/standard/config";

export default withArkEnv(nextConfig);
```

Forces Standard Schema-compatible generated imports.

## Flat vs strict

Public keys use the `NEXT_PUBLIC_` prefix. Flat mode uses one schema file plus a runtime Proxy that blocks server-key reads on the client.

Strict mode splits modules so the server schema never enters the client graph:

```ts title="./env/server.ts"
import arkenv from "@arkenv/nextjs/server";
import { env as clientEnv } from "./client";

export const env = arkenv(
	{ DATABASE_URL: "string" },
	{ extends: [clientEnv] },
);
```

Scaffold with `arkenv init --strict`. Guide: [Client vs. server](/docs/validating-environment-variables).
