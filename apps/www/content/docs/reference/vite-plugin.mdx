title: "@arkenv/vite-plugin"
description: Vite plugin for build-time validation and client env isolation.
---

`@arkenv/vite-plugin` validates environment variables during Vite dev
and build. Only public keys (default `VITE_*`) reach the client.

## Installation

```package-install
npm install @arkenv/core arktype
```

```package-install
npm install -D @arkenv/vite-plugin
```

Standard Schema entry: `@arkenv/vite-plugin/standard`.

## Exports

The default export is the Vite plugin factory. Named exports are
explicit aliases.

| Export                   | Role                          |
| ------------------------ | ----------------------------- |
| default                  | `arkenvPlugin` plugin factory |
| named `arkenvPlugin`     | Plugin factory                |
| named `arkenvVitePlugin` | Host-explicit named alias     |
| `./standard`             | Standard Schema plugin entry  |

## Transform mode

Point the plugin at your `env.ts`. The client graph is rewritten so
server secrets never inline.

```ts title="./vite.config.ts"
import { defineConfig } from "vite";
import arkenvPlugin from "@arkenv/vite-plugin";

export default defineConfig({
  plugins: [arkenvPlugin()],
});
```

```ts title="./env.ts" twoslash
import arkenv from "@arkenv/core";

export const env = arkenv({
  DATABASE_URL: "string",
  VITE_API_URL: "string",
});
```

### Transform options

Pass transform options only. A schema argument is rejected.

| Option                | Default                    | Meaning                                                            |
| --------------------- | -------------------------- | ------------------------------------------------------------------ |
| `schemaPath`          | auto (`env.ts`)            | Schema module to transform                                         |
| `clientPrefix`        | Vite `envPrefix` (`VITE_`) | Keys exposed to the client                                         |
| Plus                  | (none)                     | All [`ArkEnvConfig`](/docs/reference/options) fields except `safe` |
| `logger` / `logLevel` | (none)                     | Logging                                                            |

Call `arkenvPlugin()` with no args, or an options object that includes
transform fields (`schemaPath`, `clientPrefix`, logging). Do not pass a
schema map or compiled `type()` to the plugin.

## Values inside `vite.config.ts`

When the config file needs typed values, validate them with core
`arkenv()` and Vite's `loadEnv`. Keep the plugin on transform options
only:

```ts title="./vite.config.ts"
import { defineConfig, loadEnv } from "vite";
import arkenvPlugin from "@arkenv/vite-plugin";
import arkenv from "@arkenv/core";

export default defineConfig(({ mode }) => {
  const env = arkenv(
    {
      PORT: "number.port",
      VITE_API_URL: "string",
    },
    { env: loadEnv(mode, process.cwd(), "") },
  );
  return {
    plugins: [arkenvPlugin()],
    server: { port: env.PORT },
  };
});
```

## Types

Import the validated `env` object from your schema module. Treat
`import.meta.env` as a secondary surface; prefer `import { env } from
"./env"` for schema keys.
