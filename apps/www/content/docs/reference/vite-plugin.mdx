title: "@arkenv/vite-plugin"
description: Vite plugin for build-time validation and client env isolation.
---

`@arkenv/vite-plugin` validates environment variables during Vite dev
and build. Only public keys (default `VITE_*`) reach the client.

## Installation

```package-install
npm i @arkenv/core arktype
```

```package-install
npm i -D @arkenv/vite-plugin
```

Standard Schema entry: `@arkenv/vite-plugin/standard`.

## Transform mode

Point the plugin at your `env.ts`. The client graph is rewritten so
server secrets never inline.

```ts title="./vite.config.ts"
import { defineConfig } from "vite";
import arkenv from "@arkenv/vite-plugin";

export default defineConfig({
  plugins: [arkenv()],
});
```

```ts title="./env.ts" twoslash
import arkenv from "@arkenv/core";

export const env = arkenv({
  DATABASE_URL: "string",
  VITE_API_URL: "string",
});
```

### Transform options

Pass a config object (a schema map belongs in schema/define mode).

| Option                | Default                    | Meaning                                                            |
| --------------------- | -------------------------- | ------------------------------------------------------------------ |
| `schemaPath`          | auto (`env.ts`)            | Schema module to transform                                         |
| `clientPrefix`        | Vite `envPrefix` (`VITE_`) | Keys exposed to the client                                         |
| Plus                  | (none)                     | All [`ArkEnvConfig`](/docs/reference/options) fields except `safe` |
| `logger` / `logLevel` | (none)                     | Logging                                                            |

Empty `arkenv({})` enters **schema/define** mode. Call `arkenv()` with
no args, or an options object that includes transform fields, for
transform mode.

## Schema / `define` mode

Pass a schema (or compiled `type()`) to validate and inline
`import.meta.env`.

```ts title="./vite.config.ts"
import { defineConfig, loadEnv } from "vite";
import arkenvPlugin from "@arkenv/vite-plugin";
import arkenv, { type } from "@arkenv/core";

export const Env = type({
  PORT: "number.port",
  VITE_API_URL: "string",
});

export default defineConfig(({ mode }) => {
  const env = arkenv(Env, { env: loadEnv(mode, process.cwd(), "") });
  return {
    plugins: [arkenvPlugin(Env)],
    server: { port: env.PORT },
  };
});
```

## Types

Import the validated `env` object from your schema module. Treat
`import.meta.env` as a secondary surface.

```ts
import type { ImportMetaEnvAugmented } from "@arkenv/vite-plugin";
```
