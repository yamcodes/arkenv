ArkType via [`@arkenv/core`](/docs/reference/core). Engine choice: [Choosing an engine](/docs/core-concepts/standard-schema).

`@arkenv/core` is the default ArkEnv engine. Write ArkType DSL strings or `type()`, use keywords like `number.port`, and keep built-in [coercion](/docs/core-concepts/coercion).

## Install

```package-install
pnpm add @arkenv/core arktype
```

## Minimal `env.ts`

```ts title="./env.ts" twoslash
import arkenv from "@arkenv/core";

export const env = arkenv({
  DATABASE_URL: "string",
  PORT: "number.port = 3000",
  DEBUG: "boolean = false",
  NODE_ENV: "'development' | 'production' | 'test' = 'development'",
});
```

Import `{ env } from "./env"` at process boot. ArkEnv throws [`ArkEnvError`](/docs/reference/core) if a value is missing or invalid.

## Coercion

ArkEnv introspects the compiled ArkType schema's JSON Schema and pre-coerces env strings. You do not pass a callback.

```ts title="./env.ts" twoslash
import arkenv from "@arkenv/core";

export const env = arkenv(
  {
    PORT: "number.port",
    DEBUG: "boolean",
    TAGS: "string[]",
  },
  {
    env: {
      PORT: "8080",
      DEBUG: "true",
      TAGS: "web, api",
    },
  },
);

env.PORT; // number
env.DEBUG; // boolean
env.TAGS; // string[]
```

Set `{ coerce: false }` for raw strings and [morphs](/docs/core-concepts/transforms). See [Coercion](/docs/core-concepts/coercion).

## Defaults and optionals

| Pattern                  | Meaning                                    |
| ------------------------ | ------------------------------------------ |
| `= 'value'` / `= 3000`   | Default when the key is missing            |
| `string \| undefined`    | Optional key                               |
| `emptyAsUndefined: true` | Treat `PORT=` as missing so defaults apply |

Keywords (`string.host`, `number.port`): [keywords](/docs/reference/keywords). Morphs and `type()`: [Defining types](/docs/validating-environment-variables/defining-types).
