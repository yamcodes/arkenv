If you already validate forms or API data with ArkType, Zod, or Valibot,
these cookbooks show how to use the same library for environment
variables.

Start with
[Choosing an engine](/docs/guides/validators/choosing-an-engine) when you
are deciding between `@arkenv/core` and `@arkenv/standard`.

A one-file `Env.assert(process.env)` works for a hello-world Node
script. ArkEnv adds env-specific errors, automatic coercion, a CLI, and
framework plugins that keep server secrets out of the client graph. See
[Comparison](/docs/comparison) for DIY, T3 Env, znv, Envalid, and
related tools.
