## What is ArkEnv?

ArkEnv is a modern, lightweight, and typesafe environment variable validation library for JavaScript and TypeScript apps.

Powered by [ArkType](https://arktype.io) and [Standard Schema](https://github.com/standard-schema/standard-schema), ArkEnv lets you define, validate, and parse environment variables seamlessly across client, server, and monorepo environments.

## Why ArkEnv?

- **Zero bloat**: A tiny, dependency-free package that drops in right next to your existing validator.
- **Typesafe by design**: Infer clean TypeScript types directly from your environment schema.
- **Fail-fast validation**: Catch missing or invalid variables at dev, build, or boot time with beautiful console errors.
- **Strict client/server isolation**: Guarantee server secrets never accidentally leak into your client bundles.
- **First-class integrations**: Native plugins for Next.js, Nuxt, Vite, and Bun.
