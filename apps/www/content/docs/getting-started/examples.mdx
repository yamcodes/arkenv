title: Start with an example
description: Start with an example ArkEnv project.
---

An empty directory is the fastest way to see a typed `env` object.
ArkEnv's CLI scaffolds an example there, before you add one to your
own repo.

```package-install
npx arkenv init --example <example-name>
```

Run that in an empty directory. The CLI writes the example in place.
Pass `--force` only when you accept overwriting files that are already
there.

<Callout type="info" title="Repo already has application code?">
  Skip `--example` and follow
  [Installation](/docs/getting-started/installation) instead. Init will
  adopt the existing project.
</Callout>

## Examples

Each card is an `--example` name. Pass that name and the CLI scaffolds
the project.

<ExampleCards />

<Callout type="info" title="Want the files without the CLI?">
  `degit` copies the example directory. You still install dependencies
  and copy `.env.example` yourself.
</Callout>

```package-install
npx degit yamcodes/arkenv/examples/<example-name> <project-name>
cd <project-name>
cp .env.example .env
npm install
npm run dev
```
