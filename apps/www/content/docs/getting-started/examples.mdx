description: Start with an example ArkEnv project.
---

Use `arkenv init --example` to bootstrap a project from a template:

```package-install
npx arkenv@latest init --example with-vite-react
npx arkenv@latest init --example basic
```

Run this in an empty directory, or pass `--force` to overwrite.
`--example` always uses the new-project flow.

<Callout type="info">
  For a repo that already has application code, skip `--example` and follow
  [Add to an existing repository](/docs/getting-started/add-to-existing-repository).
</Callout>

## Examples

[`examples/`](https://github.com/yamcodes/arkenv/tree/main/examples) is a
standalone project that installs published packages from npm. Open the

Also on GitHub, not in the CLI registry:
[`basic-js`](https://github.com/yamcodes/arkenv/tree/main/examples/basic-js),
[`with-nuxt-strict`](https://github.com/yamcodes/arkenv/tree/main/examples/with-nuxt-strict),
[`with-solid-start`](https://github.com/yamcodes/arkenv/tree/main/examples/with-solid-start),
and
[`with-standard-schema`](https://github.com/yamcodes/arkenv/tree/main/examples/with-standard-schema).

You can clone an example and run it locally:

```bash title="Terminal"
git clone https://github.com/yamcodes/arkenv.git
cd arkenv/examples/basic
cp .env.example .env
```

Then install dependencies and start the app from that example's README.

Or try the
[StackBlitz demo](https://stackblitz.com/github/yamcodes/arkenv/tree/main/examples/stackblitz?file=index.ts)
in the browser. That template is adapted for WebContainer, so use a
standalone example when you want the exact production stack.
