---
title: Add to an existing repository
description: Add typesafe environment variable validation to an existing project.
---

ArkEnv can be adopted incrementally in a repo that **already has
application code**. When the interactive CLI finds a `package.json`, it
detects your stack, generates schema files, and wires framework
integrations.

<Steps>
  <Step>
    ### Run the interactive CLI

    ```package-install
    npx arkenv@latest init
    ```

    The CLI refuses a dirty git working tree. Commit or stash
    (`git stash -u`) first, or pass `--force` if you accept overwriting
    generated files.

    <Callout type="warn">
      The CLI **never** reads your actual `.env` files! Suggested schema
      key names come from `.env.example` if you have one, otherwise from
      `process.env` / `import.meta.env` usage in source.
    </Callout>
  </Step>

  <Step>
    ### Answer the wizard

    The CLI asks about framework, validator, and hosting preset. If `compilerOptions.strict` is
    off in `tsconfig.json`, the wizard offers to enable it (recommended).
  </Step>

  <Step>
    ### Review generated files

    After the CLI, a Next.js app (for example) looks like this:

    <Files>
      <Folder name="my-app" defaultOpen>
        <File name="env.ts" />

        <File name=".env.example" />

        <File name=".env" />

        <Folder name=".arkenv">
          <File name="env.gen.ts" />

          <File name="index.ts" />
        </Folder>

        <Folder name="app" defaultOpen>
          <File name="page.tsx" />
        </Folder>

        <File name="next.config.ts" />
      </Folder>
    </Files>

    If the project has a `src/` directory, the schema lands at
    `src/env.ts` instead.
  </Step>

  <Step>
    ### Import `env` in your app

    If you don't have a `.env` file yet, copy the example and fill in values:

    ```bash title="Terminal"
    cp .env.example .env
    ```

    Import `env` **instead of** `process.env` (or `import.meta.env`):

    ```ts title="./app/page.tsx" twoslash
    // @filename: env.ts
    import arkenv from "@arkenv/core";

    export const env = arkenv({
      DATABASE_URL: "string",
    });

    // @filename: app/page.tsx
    // ---cut---
    import { env } from "../env";

    console.log(env.DATABASE_URL);
    ```
  </Step>
</Steps>
