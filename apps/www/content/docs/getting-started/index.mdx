ArkEnv provides typesafe environment variable validation for JavaScript and TypeScript projects. [`@arkenv/core`](/docs/reference/core) and [`@arkenv/standard`](/docs/reference/standard) have **zero runtime dependencies**.

## Quick Start Options

- [Installation](/docs/getting-started/installation): Install ArkEnv into your project.
- [Start with an example](/docs/getting-started/examples): Explore playground templates and runnable examples.
- [Add to an existing repository](/docs/getting-started/add-to-existing-repository): Setup environment validation step-by-step.
- [Editor integration](/docs/getting-started/editor-integration): Configure your editor/IDE for auto-imports and validation tooltips.
