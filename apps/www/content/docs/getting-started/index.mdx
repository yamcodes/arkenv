If you're new to ArkEnv, you can follow these steps to get started.

<Steps>
<Step>

### Install ArkEnv

Run the interactive CLI to detect your stack, write a schema, and wire the matching
plugin.

```package-install
npx arkenv@latest init
```

To install packages by hand, see the
[installation guide](/docs/getting-started/installation).

</Step>
