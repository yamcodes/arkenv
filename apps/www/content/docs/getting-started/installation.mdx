---
title: Installation
description: Install ArkEnv core validation library and plugins.
---

Install the ArkEnv core package (`@arkenv/core`) using your package manager of choice:

```package-install
pnpm add @arkenv/core
```

## CLI tooling (optional)

To scaffold environment schemas and manage hosting provider env variables:

```package-install
pnpm add -D arkenv
```

## Framework plugins (optional)

If you are using Next.js, Nuxt, Vite, or Bun:

```package-install
# Next.js
pnpm add @arkenv/nextjs

# Nuxt
pnpm add @arkenv/nuxt

# Vite
pnpm add -D @arkenv/vite-plugin

# Bun
pnpm add -D @arkenv/bun-plugin
```
