Get started with ArkEnv in a few moments using:

```package-install
npx arkenv@latest init
```

Init detects your stack, installs the matching packages, and writes a
schema. You can also [start with an example](/docs/getting-started/examples)
or [add ArkEnv to an existing repository](/docs/getting-started/add-to-existing-repository).

## Installing packages by hand

`arkenv init` is the usual path. Install by hand when you want to pin
packages yourself.

### `@arkenv/core`

This is the ArkType engine. `arktype` is a required peer.

```package-install
npm i @arkenv/core arktype
```

If you already validate with Zod or Valibot, install
[`@arkenv/standard`](/docs/guides/validators) instead of `@arkenv/core`.

### CLI

Add the `arkenv` package when you want a project-local binary for `init`
and `add host`.

```package-install
npm i -D arkenv
```

### Framework plugins

Next.js, Nuxt, Vite, and Bun have first-party packages. Init installs the
matching one. To add them by hand, see the
[framework guides](/docs/guides/frameworks).
