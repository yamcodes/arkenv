Get started with ArkEnv in a few moments using:

```package-install
npx arkenv@latest init
```

The interactive CLI detects your stack, installs the matching packages, and writes a
schema. Use it to [start with an example](/docs/getting-started/examples)
or [add ArkEnv to an existing repository](/docs/getting-started/add-to-existing-repository).

## Manual installation

ArkEnv can be installed manually if you prefer a more hands-on approach.

### Validation engine

`@arkenv/core` is the core ArkType-powered validation engine. `arktype` is a **required** peer.

```package-install
npm i @arkenv/core arktype
```

If you already validate with Zod or Valibot, install
[`@arkenv/standard`](/docs/guides/validators) instead.

<Callout type="info">
  `@arkenv/core` can also be used with Zod or Valibot, since ArkType itself is a Standard Schema adapter. The decision is simple: if you have ArkType (or don't mind the dependency), use `@arkenv/core`. If you don't have ArkType and don't need it, use `@arkenv/standard`. The engines have **feature parity**.
</Callout>

### Framework integrations

Next.js, Nuxt, Vite, and Bun have **first-party** integrations. The CLI detects your stack and installs the matching one. To add them manually, see the [framework guides](/docs/guides/frameworks).
