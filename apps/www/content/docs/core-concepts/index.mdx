These pages explain how ArkEnv thinks about environment variables: when validation runs, how strings become typed values, and why the imported `env` object is the surface you use everywhere.

ArkEnv has two engines that share the same runtime pipeline and options:

- [`@arkenv/core`](/docs/reference/core) with ArkType
- [`@arkenv/standard`](/docs/reference/standard) with Zod, Valibot, or any [Standard Schema](https://standardschema.dev/) validator

Concept pages treat both as first-class. Examples usually show ArkType and Zod side by side; engine-only details use callouts.

For step-by-step setup, see [Validating environment variables](/docs/validating-environment-variables). For option and package lookups, see the [API reference](/docs/reference).
